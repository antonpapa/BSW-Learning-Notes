# NVM 学习
- **NvM:掉电非易失存储单元** 

## 1. 概述
- **什么是NvM？**  
  掉电非易失性存储单元，主要用于需要掉电后长期存储的数据，比如**行车里程**，**错误冻结帧**等
- **以外置Flash为例**  
  - 部分控制器选择的MCU并没有内置NVM单元，我们常用外置的flash模拟EEPROM
  - 与RAM不同，RAM支持随时读写，而flsh为异步的，我们通常将需要存储进NVM的数据先写入PROTECT-RAM，再将PRAM中的数据放入flash
  - 从flash中读数据也是同理，先将数据搬入PRAM，再读取PRAM   中的数据

## 2. EEPROM分区

### 2.1 Sector
- **扇区**：Flash擦除操作的最小单位，8Kbyte或其倍数
  | sector0 | sector1 |
  |---------|---------|
  | Block0  | Block1  |
  | ....    | ....    |
  | ....    | ....    |
  | ....    | ....    |
  | ....    | ....    |
  | ....    | ....    |
  | Blockn  | Blockn  |

### 2.2 Block
- **区块**：Flash数据管理的最小单位，申请区块用于数据存储

## 3. Page
- **页**：Flash数据写操作的最小单位，8Byte或其倍数
